# 06 - Response Compression

<div dir="rtl">

## دربارهٔ این پروژه

این پروژه به بررسی عملی مکانیزم Response Compression در ASP.NET Core می‌پردازد؛ اینکه چگونه بدنهٔ پاسخ HTTP پیش از ارسال به کلاینت فشرده‌سازی می‌شود تا حجم داده‌های منتقل‌شده روی شبکه کاهش یابد. برخلاف پروژه‌های قبلی که تمرکز بر کاهش زمان پردازش سمت سرور (از طریق کش) بود، این پروژه به بهینه‌سازی حجم انتقال داده می‌پردازد؛ موضوعی مستقل و مکمل نسبت به کش کردن پاسخ.

## سناریو و پیاده‌سازی

مراحل انجام‌شده در این پروژه به شرح زیر است:

- **ثبت سرویس فشرده‌سازی**: فعال‌سازی Response Compression با `AddResponseCompression` و افزودن دو Provider اصلی: `GzipCompressionProvider` و `BrotliCompressionProvider`، به‌طوری‌که میان‌افزار بسته به هدر `Accept-Encoding` درخواست، مناسب‌ترین الگوریتم را انتخاب می‌کند.
- **فعال‌سازی روی HTTPS**: تنظیم `EnableForHttps = true`، چرا که به‌صورت پیش‌فرض فشرده‌سازی روی اتصالات HTTPS به‌دلیل ملاحظات امنیتی (نظیر آسیب‌پذیری‌های شناخته‌شده مانند BREACH) غیرفعال است و باید آگاهانه فعال شود.
- **افزودن میان‌افزار**: استفاده از `app.UseResponseCompression()` پیش از `app.UseHttpsRedirection()` در Pipeline، جهت اطمینان از اینکه فشرده‌سازی روی پاسخ نهایی اعمال می‌شود.
- **شبیه‌سازی منبع داده**: پیاده‌سازی `DataService` جهت بازگرداندن فهرست سفارش‌ها، به‌عنوان محتوایی با حجم کافی برای مشاهدهٔ اثر عملی فشرده‌سازی.
- **اعمال روی endpoint**: تعریف `GET /orders` بدون هیچ تنظیم اضافی در سطح handler؛ فشرده‌سازی به‌طور کامل و شفاف توسط میان‌افزار مدیریت می‌شود.

## مفاهیم کلیدی

- تفاوت هدف **Response Compression** (کاهش حجم داده‌های منتقل‌شده روی شبکه) با **Output/Response Caching** (کاهش زمان پردازش یا تعداد فراخوانی مجدد منطق سرور)؛ این دو مکانیزم مستقل از یکدیگرند و می‌توانند هم‌زمان به کار روند.
- لزوم فعال‌سازی صریح فشرده‌سازی روی HTTPS با `EnableForHttps = true`، به‌دلیل غیرفعال بودن پیش‌فرض آن به‌دلایل امنیتی.
- نقش هدر `Accept-Encoding` کلاینت در تعیین اینکه کدام‌یک از Providerهای ثبت‌شده (Gzip یا Brotli) برای فشرده‌سازی پاسخ انتخاب شود.
- جایگاه صحیح `UseResponseCompression()` در Pipeline میان‌افزارها نسبت به سایر میان‌افزارها مانند `UseHttpsRedirection()`.
